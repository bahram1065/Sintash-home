سین‌تاش هوم — بارگذاری سورس در GitHub برای Railway

این بسته به‌تنهایی برنامه را منتشر نمی‌کند؛ دو فایل باید در ریشه مخزن GitHub قرار بگیرند.

۱) در GitHub مخزن bahram1065/Sintash-home را باز کنید.
۲) Add file > Upload files را انتخاب کنید.
۳) هر دو فایل زیر را انتخاب و بارگذاری کنید:
   - Dockerfile
   - sintash-home-source.tar.gz
۴) روی Commit changes بزنید و شاخه main را انتخاب کنید.
۵) Railway باید به‌دلیل وجود Dockerfile، ساخت را دوباره شروع کند.
۶) پس از ساخت موفق، در Railway یک PostgreSQL اضافه کنید و متغیر DATABASE_URL را از اتصال داخلی دیتابیس به سرویس برنامه اضافه کنید.
۷) پیش از ورود اطلاعات واقعی باید schema پایگاه داده اعمال و نقش‌ها/امنیت بررسی شوند.

هشدار:
- رمزها، کلیدهای API یا DATABASE_URL واقعی را در GitHub قرار ندهید.
- npm run db:seed را در محیط تولید اجرا نکنید؛ داده‌های seed حساب‌های آزمایشی با رمز ثابت دارند.
- تا زمانی که /api/health پاسخ HTTP 200 و database: ok نداده، برنامه را برای سفارش واقعی استفاده نکنید.

ساخت محلی/راه دور هنوز با این بسته تأیید نشده است؛ اگر Railway باز هم Failed شد، Build Logs جدید را ارسال کنید.
